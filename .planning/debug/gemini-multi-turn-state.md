## Resolution

root_cause: "The proxy had no mechanism to extract and replay Gemini web frontend conversation state. Browser captures show state is carried in inner_req_list slot 2 (conversationId, responseId, responsePartId, continuationToken) and slot 17 changes from [[0]] to [[1]] for follow-up turns. The response meta entry provides the continuation token at key '26'."
fix: "Added WebConversationState struct, stored it in WebSession, populate inner_req_list slot 2 / slot 17 based on conversation_state, and extract state from StreamGenerate responses via extract_conversation_state."
